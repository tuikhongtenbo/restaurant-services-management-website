Cách mở đúng: chạy mvn spring-boot:run rồi mở http://localhost:8080/order-flow-test.html trong trình duyệt (Chrome/Edge). Preview trong IDE có thể trống hoặc không gọi API được.

Order Flow Test

Test luồng: Đăng nhập → Đặt bàn (tùy chọn) → Order → Thanh toán (Cash/VNPay) → CLEANING → EMPTY

Chưa đăng nhập
Quyền API: Đăng nhập ADMIN / MANAGER / WAITER (có JWT). Order (/api/orders/*) — mọi user đã login. Menu public (/api/public/menu) — xem & gọi món. Tables — cần role phù hợp (ADMIN/MANAGER tạo bàn; STAFF/WAITER mở bàn). Payment (/api/payments/*) — cần role CASHIER / ADMIN / MANAGER. Customer (/api/auth/customer/*) — đăng ký/đăng nhập để gắn SĐT tích điểm khi checkout. Khuyến nghị staff: admin@restaurant.com · VNPay cần VNPAY_TMN_CODE + VNPAY_HASH_SECRET trong .env.
